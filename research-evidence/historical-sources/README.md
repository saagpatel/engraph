# Historical research source custody

`fable-t1-gate-verdict.tar` is a deterministic `git archive` of four exact
research records from commit `f69fffc1697f8974a906ec325b3f0976cf555ae2`:

- `fable-explore/05-research-notes.md`
- `fable-explore/09-t1-perf-refutation.md`
- `fable-explore/10-gpu-bound-verdict.md`
- `fable-explore/11-perf-claims-audit.md`

The archive keeps those bytes available in a checkout of this branch even if
the separate historical ref or unreachable Git objects are pruned. It is local
evidence custody, not publication, authentication, or proof that the claims are
correct.
